# Jane_Vercel_Deployment

> **Smart India Hackathon 2026 (SIH 26) - Project JANE (Frontend Web Demo)**

This repository hosts the **interactive web UI demonstration** for **Project JANE** (Joint Anonymity & Network Enumeration), deployed on **Vercel** for jury evaluation and showcase.

---

### Research & Demonstration Scope
- **Academic & Research Purpose**: Developed strictly for research, cyber defense education, and technical evaluation under **Smart India Hackathon 2026 (SIH 26)**.
- **Client-Side Simulation**: This Vercel deployment operates in **standalone demo mode**. It runs entirely in the browser using internal Next.js mock API route handlers.
- **Synthetic Data**: All threat actors, cryptocurrency addresses, network metrics, and threat graphs rendered in this deployment are **100% synthetic, fictional mock data** designed specifically to showcase the dashboard interface and analytics workflows safely without accessing any live dark web networks or sensitive external intelligence.

---

### Key Features Showcased
- **Executive Threat Intelligence Dashboard**: Macro-level metrics, category breakdowns, and activity monitoring.
- **Actor Profiling & Stylometry**: Entity resolution, aliases, and linguistic pattern analysis.
- **Threat Graph & Network Visualization**: Interactive entity relationship graphs and multi-hop link analysis.
- **Dark Web Search & Investigation Hub**: Live filtering, query expansion, and indicator extraction preview.
- **Evidence Management**: Cryptographic hashing, timestamping, and export preview.

---

### Tech Stack
- **Framework**: Next.js 15 (App Router, React 19)
- **Styling**: Tailwind CSS & Lucide Icons
- **Deployment Target**: Vercel Serverless Platform
